# SWISS-MODEL Proxy Service

Микросервис-прокси на базе FastAPI для автоматизации запросов к API SWISS-MODEL. Сервис принимает аминокислотные последовательности (FASTA), управляет жизненным циклом задач моделирования (включая работу с пользовательскими PDB-шаблонами), контролирует лимиты запросов и возвращает итоговый PDB-файл.

---

## Возможности

- **Два режима моделирования**:
  - *Automodel* — автоматический поиск шаблона в базе SWISS-MODEL по переданному FASTA.
  - *User Template* — моделирование с использованием пользовательского PDB-шаблона.
- **Отказоустойчивость и Rate Limiting**:
  - Контроль лимитов (до 100 запросов/мин и 2000 запросов/6 ч).
  - Автоматический retry с экспоненциальным backoff при получении HTTP 429.
  - Настраиваемый таймаут ожидания выполнения моделирования.
- **Валидация и безопасность**: проверка формата файлов (FASTA, PDB), валидация длины последовательностей и автоматическая очистка временных файлов после обработки запроса.
- **Готовое окружение**: изоляция в Docker и Docker Compose.

## Быстрый запуск

### 1. Настройка окружения

Склонируйте репозиторий и создайте файл `.env`:

```bash
git clone [https://github.com/chelovekkrokant/swissmodel-proxy-service.git](https://github.com/chelovekkrokant/swissmodel-proxy-service.git)
cd swissmodel-proxy-service
cp .env.example .env

```

Укажите ваш API-ключ SWISS-MODEL в `.env`:

```env
SWISSMODEL_API_KEY=your_token_here
PORT=10002
MAX_WAIT_TIME=3600

```

### 2. Запуск через Docker Compose

```bash
docker compose up --build -d

```

Сервис будет доступен по адресу: `http://localhost:10002` (интерактивная документация Swagger: `http://localhost:10002/docs`).

## Примеры использования

### Режим A: Автоматический поиск шаблона

```bash
curl -X POST [http://127.0.0.1:10002/predict](http://127.0.0.1:10002/predict) \
  -F "fasta=@sequence.fasta" \
  -o result.pdb

```

### Режим B: С пользовательским PDB-шаблоном

```bash
curl -X POST [http://127.0.0.1:10002/predict](http://127.0.0.1:10002/predict) \
  -F "fasta=@sequence.fasta" \
  -F "template=@template.pdb" \
  -o result.pdb

```

## Коды ответов API

| Код | Причина |
| --- | --- |
| **200 OK** | Моделирование успешно завершено, возвращен PDB-файл |
| **400 Bad Request** | Отсутствует файл, неверное расширение (`.fasta`/`.pdb`) или последовательность короче 30 остатков |
| **404 Not Found** | Подходящие шаблоны для структуры не найдены |
| **500 Internal Server Error** | Ошибка валидации структуры на стороне внешнего API |
| **504 Gateway Timeout** | Моделирование превысило время `MAX_WAIT_TIME` |

```
